# BREAKTHROUGH (later same session) — found the REAL template source

User rejected v1–v3 ("非常不好"), then confirmed the problem was **字体不对** and asked "有没有现成的 我们直接 copy 可以？". So instead of guessing, I pulled the RAW source of the reference site.

## The real template is **jemdoc** ⭐
`https://ycgu.site/` is generated by **jemdoc** (https://jemdoc.jaboc.net/) — a Markdown-to-HTML academic homepage generator widely used in CS. Proof: `<link rel="stylesheet" href="./index_files/jemdoc.css">`.

How to get it:
```bash
curl -sL https://ycgu.site/ -o /tmp/ycgu.html          # raw HTML (27KB)
curl -sL https://ycgu.site/index_files/jemdoc.css      # the stylesheet (5.2KB)
curl -sL https://ycgu.site/index_files/github.png      # social icons (also google_scholar.png, twitter.png)
```
Original repo: `guyuchao.github.io`.

## jemdoc.css key values — my earlier guesses were ALL wrong
| Property | Real value | What I had wrongly used |
|---|---|---|
| body font | **Georgia** (no web font!) | Crimson Pro / EB Garamond ❌ |
| body font-size | default (16px), line-height **1.3** | 17–18px / 1.6 ❌ |
| body max-width | **960px**, padding 0 50px | 880px / 36px ❌ |
| `a` color | **#224b8d**, `text-decoration: none` (underline only on hover, dotted) | #2c5aa0 + always underlined ❌ |
| h1/h2/h3 color | **#527bbd** + `border-bottom: 1px solid #aaaaaa` | #2c5aa0 ❌ |
| `ul` bullets | `list-style-type: square` | custom ▪ / ▸ ❌ |
| project name red | **#8B0000** (dark red) `font-weight:bold` | #c1383f ❌ |

## ycgu HTML structural patterns (copy these verbatim)
- **Header**: `<table id="tbHeader">` — left `<td width="670">` holds `<div id="toptitle"><h1>Name</h1></div>` + `<h3>title</h3>` + `Email: <u><a>` + icon row; right `<td>` holds `<img width="250">` portrait (plain, no shadow/radius).
- **Biography**: wrapped in `<div style="text-align:justify">`; `<strong>` for keywords; inline citations as `<a href="...">(<span style="color:#8B0000;font-weight:bold">ProjName</span>, VENUE YEAR)</a>`.
- **News**: `<li>2026 Apr: <a class="paper-award">ProjName</a> got accepted by <a>VENUE</a>.</li>`
- **Publications**: `<table id="tbPublications" width="100%">`.
  - category banner row: `<td colspan="2">` + `<div style="border-left:5px solid #8B0000;padding:5px 0 5px 14px;background:linear-gradient(90deg,rgba(139,0,0,0.08) 0%,transparent 60%);">` + `<span style="font-size:1.18em;font-weight:bold;color:#8B0000;letter-spacing:0.3px;">⚡ Category</span>`
  - paper row: left `<td width="260"><img width="240px" style="box-shadow: 4px 4px 8px #888">`; right `<td>` = `<a href><b>Title</b></a><br>` + `<b>Author</b>*, ...<br>` + `<p style="margin-top:3px">` venue `<br>` + `[<a>project</a>] [<a>paper</a>] [<a>code</a>]`.
- **Footer**: `<div id="footer"><div id="footer-text">`

## Lesson learned (important for next time)
When asked to "copy this site's look", **do not guess the font/style — curl the raw HTML and read the real CSS first.** WebFetch converts to markdown and destroys all style info; that's exactly how I got the font wrong 3 times.
